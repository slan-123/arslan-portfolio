About the Project

Life Simulator 2D is a Python and Pygame project designed to simulate different aspects of everyday life through an interactive game.

The player manages their money, hunger, energy and health while progressing through different days and seasons. The game also includes multiple jobs, minigames, achievements, random events and an inventory system.

I built the project to practise programming, game development, user interface design, object-oriented programming and problem solving.

Technologies

Python Main programming language
Pygame Game engine and graphics
JSON Save and load system
Object-Oriented Programming Reusable game components

Key Features

💰

Economy System

A changing economy and shop system where prices and player finances affect gameplay.

💼

Jobs & Minigames

Multiple jobs with different gameplay mechanics and minigames to earn money.

🏆

Achievements

An achievement system that rewards players for reaching different goals throughout the game.

🌦️

World Systems

Seasons, day and night cycles, random events and other systems that make each playthrough different.

🎒

Inventory

A reusable inventory system for managing food, energy items and other consumables.

💾

Save & Load

Player progress can be saved and loaded using JSON data.

What I Learned

Building Life Simulator 2D helped me develop my understanding of game loops, event handling, collision detection, UI design, object-oriented programming and managing larger projects.

I also learned how different systems can work together inside one game, such as the economy, inventory, jobs, achievements and progression systems.
