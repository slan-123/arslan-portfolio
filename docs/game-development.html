My Game Development Experience

Game development is one of the areas where I have been able to combine programming with creativity. I enjoy taking an idea and turning it into an interactive program where different systems have to work together.

What I've Learned

Game development has taught me that making a game is not just about writing individual pieces of code. The difficult part is making many different systems work together reliably.

I have become more comfortable debugging problems, breaking large systems into smaller parts and thinking about how changes in one part of a program can affect another.

It has also helped me improve my understanding of programming concepts such as loops, conditions, functions, objects, state management and event handling.

What's Next?

I want to continue developing my game programming skills by building larger projects and experimenting with more advanced gameplay systems.

Future projects will also give me the opportunity to improve my code structure, use version control more consistently and learn new technologies alongside Python and Pygame.
